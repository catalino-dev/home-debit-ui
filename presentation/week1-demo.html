Live demo · scenario 5

Backend errors surface, gracefully

HTTP 409 → actionable message, data kept
  • Same email resubmitted → backend returns 409 Conflict
  • UI stays on the form — no navigation, no lost input
  • Specific message: "An account with this email already exists."
  • Network failures and 400 validation errors follow the same path — mapped in the service, never parsed in the UI
