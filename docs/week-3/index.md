# Week 3 Exercises

Guides for the Week 3 learning goals — asynchronous programming with
`Future`, `async`/`await`, loading state, and robust error handling with
`try`/`catch`/`finally` and Retry — and the two user stories in the training
brief.

## Exercises
* [Load customer profile (US-05)](./load-customer-profile.md) — `Future<Customer>`, `async`/`await`, the fake service with simulated delay, and the loading state
* [Handle profile loading errors (US-06)](./handle-profile-loading-errors.md) — `try`/`catch`/`finally`, user-friendly errors, Retry, and results vs exceptions
